# OctalFont Documentation

Welcome to the **OctalFont** documentation.

OctalFont is the shared **build tool** and the home of the **Octal font families**.
The tool lives in this repository; every family is a separate repository,
mounted under `fonts/` as a Git submodule, as Google Fonts requires. Use the
sections below to navigate.

| [**Design / Overview**](design/README.md)                   | Design philosophy, geometric constraints, and visual goals       |
| [**Design / Sketches**](design/sketches/README.md)          | The sketchbook-to-font design workflow                           |
| [**Technical / Metrics**](technical/metrics.md)             | UPM, vertical metrics, and the checks that guard them            |
